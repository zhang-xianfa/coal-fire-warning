# 基于 GAT‑GRU 的煤矿采空区自燃风险时空预警模型

> 横向科研项目 · 分层图神经网络 + 熵权法风险评估

## 一、项目背景

煤矿采空区（采完后遗留下的空间）是煤自燃的高发区域，直接关系到井下安全。
工作面布置了**束管监测系统**：皮顺 / 轨顺两条巷道各埋设 3 个不同深度的束管
（共 6 个监测点），每天化验 O2、N2、CH4、CO2、CO 等气体浓度。

本项目利用监测数据做两件事：

1. **气体浓度预测**：分层图神经网络（微观 GAT + 宏观 GCN + GRU 时序），
   用过去 7 天的数据预测第 8 天各测点的 O2 / CO / CO2；
2. **风险评分与可视化**：熵权法 + 7 日趋势修正 + CO 浓度压制，
   输出 [0, 15] 风险评分与热力图，CO 超过 24ppm 触发预警。

## 二、整体架构

```
┌───────────────────── 空间建模（逐日） ─────────────────────┐
│                                                            │
│   微观层（6 个测点）              宏观层（2 条巷道）          │
│   ┌───┐  ┌───┐                   ┌───────────┐             │
│   │皮1│──│皮2│── GATConv×2 ──→   │  皮顺     │  GCNConv×2  │
│   └───┘  └───┘       ↕ 跨层交互  │   ↕  轨顺 │             │
│   ┌───┐  ┌───┐      (均值池化上送 │   ↕      │             │
│   │轨1│──│轨2│       广播下传)    └───────────┘             │
│   └───┘  └───┘                                            │
└──────────────────────┬─────────────────────────────────────┘
                       ↓ 拼接 [全部微观特征 + 全部宏观特征]
               GRU×2（2 层，Dropout 0.4）← 7 天序列
                       ↓
              MLP 预测头 → [6×3] = 各测点 O2/CO/CO2
```

**核心思想**：气体在巷道中流动，测点之间存在空间关联，用「微观 GAT +
宏观 GCN」两级图显式建模；时间维度用 GRU 捕获趋势；风险损失函数让模型
在 CO 漏报上更谨慎（详见 `training/losses.py`）。

## 五、数据流程与特征工程

1. **报表合并**：每月一个 .xls、每天一个工作表，表头占 3 行
   （列名 / 单位 / 分隔），以「序号」列识别有效数据行；
2. **清洗**：只保留每天记录数 ≥ 7 的日期（6 测点 + 回风齐全），删除回风数据；
3. **特征工程**（`dataset/coal_dataset.py`）：
   - 缺失填充：ffill（下午缺 = 上午值）→ 氧气用「同节点历史均值」→ 其余填 0；
   - 6 个基础特征 + 6 个一阶差分（按测点分组，避免节点间串扰）+
     格拉汉姆比值 `Graham_Ratio = CO/(O2+1e-5)×100` = **13 维微观特征**；
   - 宏观节点 = 所属微观节点特征的均值；
4. **图结构**：同巷道测点全连接（模拟空气流通）；皮顺 ↔ 轨顺互连；
   微观 → 所属巷道宏观节点跨层连边；
5. **滑动窗口**：7 天图序列 → 第 8 天目标（各测点 [O2, CO, CO2] 展平，18 维）。

## 六、模型细节

| 组件 | 结构 |
|------|------|
| 微观层 MicroGAT | GATConv×2（4 头 → 1 头，ELU，Dropout 0.3），输入 = 13 维气体特征 + 8 维节点嵌入 |
| 宏观层 MacroGCN | GCNConv×2（ReLU + Dropout 0.3） |
| 跨层交互 | 微观投影 → 宏观均值池化（LayerNorm 残差）；宏观投影 → 广播回微观 |
| 时序 | GRU×2（hidden 64×2，Dropout 0.4），取末层隐状态 |
| 预测头 | Linear → ReLU → Dropout(0.4) → Linear |
| 损失 | RiskAwareLoss：O2 权重 15.0 / CO 漏报惩罚 2.0 / CO2 权重 5.0 |
| 优化 | Adam（lr 5e-4，weight_decay 1e-2），小 batch 8，50 epochs，按验证损失保存最优模型 |
| 数据划分 | 70/15/15（seed 42），StandardScaler 只在训练集拟合 |
| 物理约束 | 评估时预测值截断 ≥ 0，O2 截断至 [0, 22]% |

## 七、风险评分模型

风险分 = **熵权法基础得分 × 7 日趋势因子 × CO 浓度压制**，区间 [0, 15]：

| 分数 | 0–3 | 3–6 | 6–9 | 9–12 | 12–15 |
|------|-----|-----|-----|------|-------|
| 等级 | 安全 | 低风险 | 预警 | 中风险 | 高风险 / 极危 |

- **熵权法**：6 个特征（CO、CO2、O2 消耗、CO/CO2 日增量、格拉汉姆比值）按
  信息熵自动赋权；
- **趋势因子**：最近 7 天气体变化率的加权和（浓度越偏离常态权重越大），
  tanh 映射后落在 [0.8, 1.5]；
- **CO 压制**：CO < 24ppm 时指数强压制低浓度下的虚高分数，≥ 24ppm 不压制。

## 九、设计问答（FAQ）

- 为什么用图神经网络？→ 测点间有气体流动的物理关联，全连接/CNN 无法表达
  巷道拓扑；GAT 还能自动学习测点间的注意力权重。
- 为什么分层（微观+宏观）而不是一层图？→ 单层图只能做同尺度聚合；微观 GAT
  捕获测点间细节，宏观 GCN 抽象巷道级趋势，跨层交互双向传递信息。
- 为什么要节点身份嵌入？→ 图内节点按位置排序，GAT 本身对节点顺序不敏感，
  嵌入让模型知道「自己在哪个测点」，与 GNN 的消息传递互补。
- 为什么 CO 漏报惩罚只设 2.0？→ 漏报在安全场景代价高，但 5.0 会让模型
  虚报 CO（预测值飙到 10.7ppm），虚报同样伤害系统可信度，2.0 是折中。
- 为什么格拉汉姆比值用 CO/O2？→ Graham 系数是煤自燃经典指标，CO 生成量
  与 O2 消耗量的比值反映氧化程度，比单看 CO 更抗环境干扰。
- 小样本（约 300 天）如何防过拟合？→ weight_decay 1e-2、全链路 Dropout、
  小 batch、隐藏层收窄到 64、按验证损失保存最优模型。
